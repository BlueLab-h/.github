# BlueLab

BlueLab is a **non-profit volunteer experimental laboratory** that tests and develops technologies, mainly focused on **video games** and **cybersecurity**.

Our software is primarily written in **C++**, a deliberate technical choice — the language is well known for its performance and its massive use in the video game industry, which is at the core of what BlueLab is about, making it a natural fit.

Most of our projects are experimental and may contain bugs or vulnerabilities. You are welcome to contribute to them for free — just make sure to read the **CONTRIBUTING** file of each project first.
